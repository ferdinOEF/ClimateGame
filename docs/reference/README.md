# Reference material

The hazard-visuals brief names a reference prototype,
`hazard_vfx_prototype.html` (a 2D canvas mock-up of the Cyclone, Flood and
Cyclone + flood finale animations), to be kept here.

**That file never reached the session that built the hazard visuals.** It was
not among the uploads, and it is on no branch of this repository. The
visuals were therefore built from the brief's written description of its
timings, colours and behaviour. The decisions are logged in
`docs/PROGRESS.md`, under "Hazard visuals and fixes".

The earlier mock-up, `docs/design/khazan_hazard_prototype.html`, is a
different, older piece: a khazan flood demo with no cyclone spiral, river
swell or backwater.

**If the prototype is added here later**, the visuals should be compared
against it side by side.
